# Recovery inventory

Every place outside the single-player files that refers to the single-player game *HighPriest*, with a verdict per site: **added** (deleted in M1.2) or **replaced** (restored in M1.3 to M1.5, with the evidence used). Steps M1.1 to M1.5 of the [implementation plan](implementation-plan.md); the method is in the [technical plan](technical-plan.md), section 3.2.

The list was taken from the source before the removal (`macos-port` at 5b896c6) with

```bash
port/tools/inventory.py                      # one line per site: file:line: [enclosing function] names: text
port/tools/inventory.py --names              # the derived name lists
port/tools/inventory.py --markdown --verdicts port/tools/inventory-verdicts.tsv   # the table below
```

The tool derives its names from the five files as they are on `main` (`--names-from`), so it keeps working after the files are gone; on the recovered tree it reports nothing and exits 0. The table below was generated from the tree before the removal (`git archive 80d7ec3 src sources.mk`, then `--tree` on that copy). The sites found otherwise and the one site left open follow it.

## Evidence

Code and protocol come first (technical plan 3.2). From step M1.4 on, the stock 2008-09-03a client was available (`port/tools/refexe.sh`, [reference-exe.md](reference-exe.md)); where it was read, the address of the function is cited. It is two months older than this source, so a difference in a message text or a packet is not by itself evidence of the single-player game.
